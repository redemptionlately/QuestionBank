# 鹈鹕骑自行车插画设计

## 目标

创建一个可直接在浏览器打开的独立 HTML 页面，以内嵌 SVG 绘制一只骑自行车的鹈鹕。画面轻松、童趣，主体清晰，并能适应不同屏幕尺寸。

## 方案

- 使用纯 HTML、CSS 和内嵌 SVG，不引入外部依赖或图片资源。
- SVG 以 `viewBox` 定义稳定的插画画布，通过响应式尺寸保持构图比例。
- 插画包含鹈鹕、自行车，以及简洁的天空和地面衬景；鹈鹕与自行车是视觉焦点。
- 页面仅呈现插画，不增加无关的导航、说明文案或交互控件。

## 验收标准

- HTML 文件可直接打开并完整显示插画。
- 鹈鹕可辨认，且明确呈现骑自行车的姿态。
- 窄屏与宽屏下画面均不溢出、不变形。
- SVG 使用可访问性语义描述插画内容。

## 范围外

- 不修改 QuestionBank 应用本身、后端、既有前端模块或依赖配置。
- 不加入动画、外链资源或额外页面功能。
