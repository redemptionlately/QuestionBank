# 必须会背会写的验收

- 为题库发布、练习提交或异步导入任选一个场景写完整系统设计：需求、API、表、状态、事务、并发、缓存、队列、观测和容量假设齐全。
- 设计 offset 与 keyset 分页接口，写出稳定排序、游标编码和删除/插入期间的边界。
- 用 STAR 讲述一个已真实验证的 M0 难点，并明确已实现、已测试、仅设计和未掌握内容。

# 额外测试与追问

- 面对 QPS 增长 10 倍、数据库故障、消息重复和缓存雪崩分别给出演进顺序。
- 为 API 设计版本兼容、错误响应、幂等键和安全审计字段。
- 进行一次 30 分钟模拟面试，记录回答缺口并回填对应 Day 的复习项。
